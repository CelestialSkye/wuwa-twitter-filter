# wuwa-twitter-filter
browse your timeline in peace

A filter list for Wuwa twitter. It hides accounts that spam the same anti Wuwa talking points and buzzwords, as well as gacha grailers, so you can actually read replies under Wuwa posts in peace.

## Why

Real criticism of the game keeps getting drowned out by the same repeated talking points and buzzwords, "harem slop", "it's a copy", "dead game", you know the ones. And it's not staying in random threads anymore, it reached official Kuro posts.

This isn't about building an echo chamber. It's the opposite. It filters out the noise so actual criticism can be seen and talked about. Criticize the game all you want, valid criticism doesn't get you on the list.

## How to use it

### Option 1: subscribe (recommended)

1. Install the [Twitter Filter](https://store.rxliuli.com/extensions/twitter-filter/) extension for your browser
2. Open it on x.com and search `Wuwa Misinformation & Gacha Grail` in the extension's shared rules search bar
3. Hit subscribe, that's it

Subscribing keeps you on the latest version of the list automatically. Their tweets get hidden from your timeline and from replies under any post, and it all runs in your browser.

### Option 2: import the file

If you'd rather manage it yourself, or want to use a different tool:

- **Twitter Filter:** Add Rule → CSV → pick `twitter_filter_import.csv`, choose Hide or Block, save
- **Other tools:** `twitter_filter_handles.txt` is the same list, one handle per line

Imported lists don't update on their own, so grab the files again when the list changes.

## Files

| File | What it is |
|---|---|
| `twitter_filter_import.csv` | The list with a `screen_name` column, ready for Twitter Filter's CSV import |
| `twitter_filter_handles.txt` | Same list, one handle per line |

## A few things

- Being on the list doesn't mean someone is a horrible person, and not everyone on it is "bad" on the same level. It's just about browsing in peace.
- Please don't use this list to go after anyone. Don't harass them, quote-tweet them or brigade them. The whole point is to see less of this stuff, not to start more drama.
- Every account was checked one by one against their recent posts, nobody's on here just for using a word or for who they follow.
- If you think you're on it by mistake, DM me on twitter ([@SkyeA2_](https://x.com/SkyeA2_)) or open an issue here and I'll take another look.

Enjoy your games!
